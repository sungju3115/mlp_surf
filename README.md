# MLP SURF 홈페이지 (만리포 로컬 서프 베이스)

충남 태안 만리포해변 서핑샵 MLP SURF의 마케팅 사이트. 순수 HTML/CSS/JS 정적 사이트 — 빌드 과정 없음, 호스팅에 바로 배포 가능.

## 실행

- `index.html`을 브라우저로 열거나, `python3 -m http.server 8000` 후 접속.

## 파일 구조

```
mlp-surf/
├── index.html      # 홈 (히어로 슬라이드, 소개+영상, 공신력, 지표, 강습, 렌탈, 시설, GOAT, 예약)
├── about.html      # 소개 — 브랜드 스토리 + 강사 프로필 3인
├── lessons.html    # 전체 강습 (8종 / 입문·체험, 레벨업·회차권, 무제한)
├── rental.html     # 렌탈 전체 (5종 / 보드, 웻슈트, SUP — 실제 가격 반영)
├── facility.html   # 시설 + 위치 (상단바 '시설 · 위치' 연결 페이지)
├── location.html   # 위치 단독 페이지 (푸터에서 접근)
└── img/            # 사용 이미지 (히어로, 강습, GOAT, 시설, 소개)
```

## 디자인 토큰 (모든 페이지 :root 공통)

- 네이비 `#24438f` / 딥네이비 `#0b2456` / 아쿠아 `#01b6ed` / 옐로 `#fbb900` / 레드 `#e30b13`
- 배경 `#f2f2f2` / 텍스트 `#2e2e2e` / 보조 `#6a6a6a` / 라인 `#dcdcdc`
- 폰트: GmarketSans(디스플레이, CDN), Pretendard(본문, CDN) — preload + `font-display:block`
- 레퍼런스 무드: wavepark.co.kr (비비드, 필 버튼, 원형 그래픽)

## 공통 인터랙션 (각 페이지 하단 인라인 JS)

- 히어로 3장 크로스페이드(5초, 홈만), 스크롤 등장 애니메이션(`.reveal` + IntersectionObserver)
- 주소·전화 클릭 복사 + 토스트, 스크롤 시 헤더 그림자
- 플로팅 버튼 3종(카카오톡·인스타 DM·TOP) — 스크롤 400px에서 표시, 호버 시 좌측 라벨

## 참고 사항

- 데스크톱(1440px) 우선. 모바일 반응형 미적용 — 개발 시 브레이크포인트 추가 필요.
- 인스타 DM 버튼은 `ig.me/m/mlpsurf_official` 딥링크(로그인 상태에서 동작).
- 지도는 구글맵 임베드(무키). 네이버 예약 버튼은 플레이스 검색 링크 — 예약 전용 링크 확보 시 교체 권장.
- 대형 PNG 이미지가 일부 있음(GOAT·시설, 2~4MB) — 배포 전 WebP/JPG 변환 권장.
- 렌탈 가격은 실운영 기준 반영(2026-07 기준): 소프트탑 25,000 / 에폭시·PU 40,000 / SUP 40,000 / 하계 3mm 15,000 / 동계 5mm 20,000 (종일 기준).
